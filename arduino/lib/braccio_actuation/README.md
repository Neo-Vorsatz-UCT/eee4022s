# Actuation Library for Tinkerkit Braccio controlled with Arduino
## Overview
This library is a re-implementation of the Braccio library for Arduino. This implementation offers more functionality, with more granular control as well as advanced features, such as non-blocking control with exponential smoothing. It's also the seed for the independent [Braccio Actuation](https://github.com/Neo-Vorsatz/Neo-Libraries/tree/main/braccio_actuation) library. The implementation in this repository is deprecated, but the independent library may receive future maintenance and improvements.

\section{Mission requirements of the product}
\label{sec:mission_requirements}
The proposed system is a library of functions and data structures written in Rust. The Mission-critical requirements for this project are as follows:
\begin{itemize}
    \item The program must successfully compile.
    \item The mapping algorithm must be valid.
    \begin{itemize}
        \item The program must correctly map the position of one limb to a position for another limb, given a set rules specified by the user.
        \item The program must work for an arbitrary pair of source and destination limbs.
        \item The program's mapping must be smooth (continuous and differentiable) such that the destination limb does not jerk due to the algorithm.
    \end{itemize}
    \item The mapping algorithm must work in realtime.
    \begin{itemize}
       \item The program must create mappings from snapshots of positions, not entire trajectories.
       \item The mapping algorithm must be fast; little contribution to latency.
    \end{itemize}
\end{itemize}

\section{Student tasks}
\label{sec:student_tasks}
The student is tasked with completing the following:
\begin{itemize}
    \item Familiarise themself with various kinematic-mapping algorithms, and select / create one to be implemented.
    \item Then program a general implementation of the mapping algorithm, allowing for various kinematic models.
    \item Create a testbench to verify the correctness of the implementation, and test performance.
    \item Implement an arm-tracking computer vision algorithm, that gives a model of a human's hand.
    \item Wirelessly transmit setpoints from the student's laptop to the Braccio arm.
    \item Implement a simple control program that moves the Braccio arm to the received setpoints.
    \item Interface all of the subsystems.
    \item Perform an attack-surface analysis of the entire system.
\end{itemize}
